ARTIFACT DETECTION VARIABLES
============================

Configuration file
------------------
Default path: configs/pipelines/artifact_detection.yaml

The script hypnose_eeg/preprocessing/detect_artifacts.py reads the variables below
from the artifact_detection section of this YAML file. Command-line arguments
override the indicated configuration values for a single run.

ARTIFACT THRESHOLDS
-------------------

artifact_detection.thresholds.robust_z
  Type: positive float
  Default: 5.0
  CLI: --robust-z-threshold
  Purpose: Moderate robust upper-Z threshold. EEG and EMG scores are calculated
  separately for each channel and sleep state.

artifact_detection.thresholds.extreme_z
  Type: positive float
  Default: 8.0
  CLI: --extreme-z-threshold
  Purpose: Extreme robust upper-Z threshold. One EEG feature above this value is
  sufficient to flag its EEG channel-epoch pair.

artifact_detection.thresholds.minimum_standard_deviation_uv
  Type: nonnegative float
  Default: 0.1
  Units: microvolts
  CLI: --min-std-uv
  Purpose: Epochs below this EEG standard deviation are treated as flatlines.
  This hard-failure rule is not sleep-state dependent.

artifact_detection.thresholds.maximum_edge_fraction
  Type: fraction from 0 to 1
  Default: 0.02
  CLI: --max-edge-fraction
  Purpose: Maximum allowed fraction of samples equal to the epoch's exact
  minimum or maximum. Larger values indicate clipping or repeated edge values.
  This hard-failure rule is not sleep-state dependent.

artifact_detection.thresholds.robust_mad_scale
  Type: positive float
  Default: 1.4826
  Purpose: Scale applied to median absolute deviation so it approximates
  standard deviation for normally distributed data.

artifact_detection.thresholds.soft_features_required
  Type: positive integer
  Default: 2
  Purpose: Number of moderately abnormal EEG features required to flag an EEG
  channel-epoch pair when no single feature exceeds extreme_z.

artifact_detection.thresholds.emg_soft_features_required
  Type: positive integer
  Default: 2
  Purpose: Number of moderately abnormal EMG features required to classify an
  EMG channel-epoch pair as extreme when no EMG feature exceeds extreme_z.

artifact_detection.thresholds.emg_supported_eeg_features_required
  Type: positive integer
  Default: 1
  Purpose: Number of moderately abnormal EEG features required for extreme EMG
  to contribute to EEG artifact rejection. Extreme EMG alone does not reject an
  epoch, which avoids treating normal wake muscle tone as an EEG artifact.


EEG FEATURES USED BY THE ALGORITHM
----------------------------------

peak_to_peak_uv
  Epoch maximum minus minimum, in microvolts. Sensitive to large deflections,
  movement, and electrode pops.

rms_uv
  Root-mean-square EEG amplitude, in microvolts.

max_derivative_uv_per_sample
  Largest absolute sample-to-sample voltage change in the epoch.

std_uv
  EEG standard deviation, in microvolts. Used by the state-independent flatline
  check rather than robust outlier scoring.

edge_fraction
  Larger of the fractions at the exact epoch minimum and maximum. Used by the
  state-independent clipping/repeated-edge check.

high_frequency_power_uv2
  Welch PSD integral over high_frequency_band_hz, in microvolts squared.

line_noise_power_uv2
  Welch PSD integral over line_noise_band_hz, in microvolts squared.

broadband_power_uv2
  Welch PSD integral over the whole analysed band (minimum_frequency_hz to
  maximum_frequency_hz), in microvolts squared. Not scored by the detector;
  the pre-scoring scan uses its square root as the dead-signal check.

nonfinite
  True when the epoch contains NaN or infinite EEG samples. This is an immediate
  state-independent hard failure.

The robust EEG score is calculated for peak_to_peak_uv, rms_uv,
max_derivative_uv_per_sample, high_frequency_power_uv2, and
line_noise_power_uv2. Each reference distribution is specific to
EEG channel x sleep state.


EMG FEATURES USED BY THE ALGORITHM
----------------------------------

emg_peak_to_peak_uv
  EMG epoch maximum minus minimum, in microvolts.

emg_rms_uv
  Root-mean-square EMG amplitude, in microvolts.

emg_max_derivative_uv_per_sample
  Largest absolute sample-to-sample EMG voltage change.

emg_nonfinite
  True when the EMG epoch contains NaN or infinite samples.

Each EMG reference distribution is specific to EMG channel x sleep state. EMG
checks are disabled when the FIF file contains no channel typed as EMG.


ROBUST SCORE
------------

Positive-valued scored features are transformed with log10 before thresholding:

  robust_z =
      (log10(feature) - median(log10(feature)))
      / (robust_mad_scale * MAD(log10(feature)))

where MAD is the median absolute deviation within the relevant channel and sleep
state. When MAD is zero, finite values receive a robust score of zero.


FINAL ARTIFACT DECISION
-----------------------

An EEG channel-epoch pair is marked as an artifact when any of the following is
true:

1. EEG contains nonfinite values.
2. EEG standard deviation is below minimum_standard_deviation_uv.
3. EEG edge fraction is above maximum_edge_fraction.
4. At least soft_features_required EEG features exceed robust_z.
5. Any EEG feature exceeds extreme_z.
6. EMG is extreme and at least emg_supported_eeg_features_required EEG features
   exceed robust_z.

An epoch is marked as an artifact when any EEG channel is marked as an artifact.
The artifact_features output column records the responsible channel-qualified
features and hard-failure reasons.


PRE-SCORING ARTIFACT SCAN
=========================

Script: hypnose_eeg/preprocessing/prescan_artifacts.py
Config section: artifact_prescan (same YAML file)

This scan runs before sleep scoring, so it has no sleep states. It looks for
long periods of unusable signal, and sleep scoring leaves those periods out.
Epoch length, chunking and Welch settings are taken from artifact_detection
above, and robust_mad_scale is shared too.

artifact_prescan.dead_signal.minimum_broadband_rms_uv
  Type: nonnegative float
  Default: 10.0
  Units: microvolts
  CLI: --minimum-broadband-rms-uv
  Purpose: An EEG channel-epoch whose broadband RMS
  (sqrt(broadband_power_uv2)) is below this value carries no EEG. The
  threshold is absolute, so it still works when most of a recording is dead.
  It catches disconnected headstages that drift slowly instead of sitting
  perfectly flat, which somnotate's own gap detection misses. On the
  calibration sessions, dead signal measured about 3.5 uV and the 1st
  percentile of clean recordings was 27-33 uV.

artifact_prescan.hard_failure.maximum_edge_fraction
  Type: fraction from 0 to 1
  Default: 0.02
  Purpose: As thresholds.maximum_edge_fraction; clipping or repeated edge
  values. Non-finite samples are also a hard failure.

artifact_prescan.extreme.robust_z
  Type: positive float
  Default: 10.0
  CLI: --extreme-z-threshold
  Purpose: Robust upper-Z threshold, computed per channel against the
  recording's live epochs only (not dead, not hard failure), so that real EEG
  is not judged against a dead majority. There are no sleep states at this
  point, so the threshold has to stay far above the post-scoring one.
  Otherwise ordinary active wake gets excluded.

artifact_prescan.extreme.features_required
  Type: positive integer
  Default: 2
  Purpose: Number of extreme.features that must exceed extreme.robust_z for
  an EEG channel-epoch to count as extreme.

artifact_prescan.extreme.features
  Type: list of EEG feature names
  Default: peak_to_peak_uv, rms_uv, max_derivative_uv_per_sample,
  high_frequency_power_uv2

artifact_prescan.periods.merge_within_s
  Type: nonnegative float
  Default: 30.0
  Units: seconds
  CLI: --merge-within-s
  Purpose: Flagged runs separated by at most this much clean signal are
  joined into one run. This stops a noisy block with the odd clean-looking
  epoch from being split into many short runs.

artifact_prescan.periods.minimum_run_s
  Type: nonnegative float
  Default: 60.0
  Units: seconds
  CLI: --minimum-run-s
  Purpose: Runs shorter than this are dropped. Brief artifacts are left for
  the post-scoring detector.

artifact_prescan.periods.bridge_gap_s
  Type: nonnegative float
  Default: 300.0
  Units: seconds
  CLI: --bridge-gap-s
  Purpose: Periods separated by less than this much clean signal are bridged
  into one continuous artifact period. Bridging happens after minimum_run_s,
  so a lone short artifact cannot chain two distant periods together.

artifact_prescan.output.suffix / artifact_prescan.output.overwrite
  Default: "prescan_artifacts" / false
  Purpose: Outputs are written as <recording>_prescan_artifacts.csv and
  .parquet in the session's artifacts folder, with one row per period:
  start_s, end_s, duration_s, flagged_fraction, dead_epochs,
  hard_failure_epochs, extreme_epochs.

An epoch is flagged when any EEG channel is dead, fails hard, or is extreme.
When configs/pipelines/sleep_scoring.yaml sets
sleep_scoring.use_artifact_prescan (true by default), sleep scoring passes
the periods to somnotate. Somnotate treats them like missing data: they are
trimmed, masked or split around, kept out of normalization, and labelled
Undefined with kind "artifact" in the predictions parquet.
